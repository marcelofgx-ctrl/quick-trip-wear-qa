Solo cartelera, sin publicidad de otros portales, con atribución visible, fechas del proveedor, horarios locales, actualización manual y manejo de fallos.
Fuentes: https://www.avionio.com/widget/es/mvd/arrivals?style=3 y https://www.avionio.com/widget/es/mvd/departures?style=3
