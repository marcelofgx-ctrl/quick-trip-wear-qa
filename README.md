# Quick Trip Wear QA v0.1

Aplicación de demostración **independiente** para Galaxy Watch / Wear OS.

- Solicitudes y viajes ficticios, sin GPS ni comunicaciones.
- No integra Supabase, Quick Trip ni Mapa QT.
- El workflow de GitHub Actions compila una APK debug para pruebas, sin publicar a tiendas.
- **Importante:** proyecto QA, no apto para aceptar viajes reales.

Compilación: Actions → Quick Trip Wear QA v0.1 → Artifacts (`app-debug.apk`).
