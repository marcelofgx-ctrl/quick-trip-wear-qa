# Vuelos Uruguay — APK Android
Pequeña aplicación independiente para consultar vuelos desde un teléfono Android.

- **Llegadas:** panel oficial del Aeropuerto de Carrasco.
- **Salidas:** Avionio (proveedor tercero).
- **Próximos días:** Flight.info (proveedor tercero).
- **Rastreo:** FlightAware (proveedor tercero).
- Botones **actualizar** y **abrir en navegador**.
- Sin registro, sin API propia, sin extracción de datos ni servicios pagos.
- Precisa conexión a Internet. La disponibilidad y precisión dependen de cada proveedor.
- No asociada a Quick Trip ni al Aeropuerto de Carrasco.

Compilación: GitHub Actions / Gradle 8.11.1 / Android SDK 35, Java 17. Paquete `uy.vuelos.uruguay`.
Descarga gratuita de APK desde Releases o Actions.
